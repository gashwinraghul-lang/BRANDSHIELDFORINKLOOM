# BrandShield.ai

BrandShield.ai is an intelligent brand‑governance platform that reviews content before publication against approved guidelines, facts, terminology, and brand assets. It provides AI‑powered findings with explanations, sources, and suggested fixes, while preserving human final decision control.

## Quick Start
```bash
# Clone the repo (if you are not already in the folder)
# cd into the project directory
docker compose up --build   # starts MySQL, client, server, and agent
npm run dev                # runs client, server, and agent in watch mode (if not using Docker)
```

See the full setup instructions in the **README** sections below.
